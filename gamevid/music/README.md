# music/

Put **royalty-free** tracks here (mp3/wav/m4a/ogg/flac). Next to each track,
add a licence note with the same name plus `.license.txt`. For example,
`chill-loop.mp3` gets `chill-loop.mp3.license.txt`, containing the source URL
and the licence terms. The export step (build step 5) lists the licence for
your video description.

Tracks in this folder are not committed to git.
